# Validation and publication boundary

## Evidence classes

| Artifact or check | Class | Publicly reproducible scope |
|---|---|---|
| `src/a255885.c` built by `src/Makefile` | production implementation | Complete inverse sieve, persistent run state, result extraction, and identity/coverage verifier. |
| `validation/validate_a255885.py` | independent bounded definition oracle and production regression | Direct Python definition through `B=2024`, local-root/cascade checks, thread and segment equality, persistence faults, locking, saturation, and CLI failures. |
| `validation/a255885_independent.c` | independent full-frontier arithmetic backend | Exact 32-bit counter recomputation, Hensel-based local roots, different projection tie break, direct omitted-factor exponent checks, minima comparison, and witness generation. |
| `validation/check_data.py` | public certificate and data verifier | Reconciles all 254 minima, 85 contiguous and 23 sparse rows, run metadata, and directly checks all 5725 witnesses. |
| `validation/manifest.tsv` and `certificate.tsv` | archival exact evidence | Byte-exact official telemetry and independent post-result certificate. |
| `results/minima.tsv` | normalized publication view | Comment-headed rendering of all 254 exact minimum-or-undefined slots. |

The production `verify` command checks identity, persistence, complete
coverage, and result derivation. It is not called an independent arithmetic
check. The bounded Python suite is independent of the production root/CRT
kernel on its finite test domain. The full C validator is implementation-level
independent: it necessarily shares the mathematical prime-power/CRT framework
proved in the paper.

## Official run

The byte-exact `config.tsv` and `manifest.tsv` record a single segment over
`c=4..1999999999`, five production threads, 1901777711 composite moduli,
273026083586 projected roots, 628611669 counter increments, zero saturation
events, and 733.563105046 seconds in the kernel. Human-facing descriptions
round this to about 734 seconds.

The independent arithmetic engine used 16 threads. Its certificate preserves
the exact recorded arithmetic time of 403.154353375 seconds; human-facing
prose rounds this to about 403 seconds.

## Original validation wrapper boundary

The official one-shot Python wrapper was tightly bound to the local campaign
directory, frozen binary hashes, multi-gigabyte checkpoints, and an absent
certificate target. It is not copied as though it were a package-relative
public runner. The compact `run.sh` exposes the same reproducible stages:
bounded regression, full production replay, production verification,
independent C recomputation, and certificate/data checking. The executable
statements of the arithmetic engine and the bounded regression suite are
unchanged; only the copyright-holder name in the source header was corrected.

## Publication identity

Carlo Corti. The copyright-line correction changes source identity metadata
only; it does not alter executable statements or the mathematical algorithm.
